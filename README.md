# Dark Romance Promo

Studio de visuels vidéo & images pour auteurs de dark romance.

## Fonctionnalités

- Créer un teaser à partir d'une idée de scène
- Générer des personnages avec l'IA ou importer des photos
- Choisir le format : image, vidéo, ou les deux
- Formats disponibles : 9:16 (TikTok/Reels), 4:5, 1:1

## Stack

- Next.js 15 (App Router)
- Tailwind CSS
- Déploiement Vercel
- API Seedance 2.5 pour la génération vidéo (à connecter)

## Démarrage

```bash
npm install
npm run dev
```
